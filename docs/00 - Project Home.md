# PromptVault — Project Home

**Project:** PromptVault
**Status:** Deployed
**Type:** Full-Stack Web Application

## Project Overview

PromptVault is a web application for creating, saving, organizing, and reusing AI prompts and personas.

The project uses Next.js, TypeScript, Supabase, GitHub, and Vercel.

## Technologies Used

- Next.js — Web application framework
- TypeScript — Programming language
- Supabase — Authentication and database
- PostgreSQL — Database system
- Vercel — Website hosting
- GitHub — Source code and version control
- Claude Code — AI-assisted development
- Visual Studio Code — Development environment

## Main Features

- User registration and login
- User logout
- Password reset
- Create, edit, and delete prompts
- Create and manage AI personas
- Search and filter prompts
- Copy prompts for reuse
- Persistent database storage
