# PromptVault Engineering Documentation

This folder contains the engineering documentation for PromptVault, a full-stack web application for storing, organizing, and reusing AI prompts and personas.

## Documentation

The notes cover:
- Project overview and architecture
- Supabase database and authentication
- GitHub and Vercel deployment
- Development and troubleshooting
- Testing and verification
- Lessons learned and future improvements
