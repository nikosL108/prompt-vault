# PromptVault — Project Overview

## Project Purpose

PromptVault is a full-stack web application designed to help users store, organize, and reuse AI prompts and personas in one place.

Instead of keeping prompts scattered across documents, notes, and AI conversations, users can manage them through a centralized web interface.

## Problem Being Solved

As AI tools become more common, users may accumulate many prompts for different tasks.

Without an organized system, it can become difficult to:
- Find previously used prompts
- Keep track of different versions
- Organize prompts by purpose
- Reuse effective instructions
- Manage AI personas

PromptVault addresses these problems by providing a searchable library for storing and managing prompts.

## Project Goals

The main goals of this project were to:

1. Build a functional web application using modern development tools.
2. Implement user authentication.
3. Connect the application to a cloud-hosted database.
4. Allow users to create, read, update, and delete saved prompts.
5. Provide AI persona management and search functionality.
6. Deploy the application publicly using Vercel.
7. Gain experience with GitHub, debugging, and full-stack development.

## Technologies

- Next.js and TypeScript for the application
- Supabase for authentication and database storage
- PostgreSQL as the underlying database
- GitHub for version control
- Vercel for production deployment
- Claude Code for AI-assisted development

## Final Outcome

PromptVault was successfully deployed as a web application.

The development process included configuring cloud services, implementing application features, testing authentication, troubleshooting deployment problems, and correcting navigation errors.

The project provided practical experience working with frontend development, backend services, version control, and deployment.
